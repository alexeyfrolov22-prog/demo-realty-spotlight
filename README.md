# Демо главной страницы сайта недвижимости — версия со световым «фонариком»

Демонстрация анимационных приёмов на статичной вёрстке главной страницы. Обезличенная сборка: название компании, логотип и фирменные иконки заменены нейтральными, коммерческий шрифт заменён на свободный.

## Что показано

- **Интро-«фонарик».** Страница открывается затемнённой, за курсором открывается «окно» в цветное изображение сайта. Через пять секунд затемнение уходит само.
- **Появление блоков при прокрутке** — разделы мягко проявляются и чуть всплывают.
- **Раскрытие заголовка** — строки первого экрана выезжают одна за другой.
- **Счётчики цифр** — числа добираются до значения, когда блок появляется на экране.
- **Магнитные кнопки** — кнопка слегка тянется к курсору.
- **Параллакс** — фон первого экрана, изображение здания и фоновые элементы формы двигаются с разной скоростью.
- **Собственный курсор** — крупная точка вместо системной стрелки.

Все эффекты отключаются при включённом в системе режиме уменьшенной анимации и не активны на сенсорных экранах.

## Запуск

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000/`.

## Шрифты и лицензии

- **Inter** — SIL Open Font License 1.1, свободен к распространению.
- **Open Sans** — Apache License 2.0.
- **Font Awesome** (иконки) — свободная версия.

Коммерческий шрифт исходной вёрстки в сборку не включён.

## Оговорка

Это учебно-демонстрационная сборка приёмов анимации. Логотип, название и фирменная символика — вымышленные placeholder-элементы и не относятся к какой-либо действующей компании.
